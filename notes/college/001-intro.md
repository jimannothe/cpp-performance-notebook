# 001 intro (college)

## Core class points

- C++ is multi-paradigm: procedural, object-oriented, and generic programming.
- Build pipeline reminder: preprocess -> compile -> link -> execute.
- Type safety matters: implicit conversions can change results silently.

## Professor emphasis

- Write readable code first, then optimize with measurements.
- Prefer explicit types when teaching and debugging fundamentals.
- Use compiler warnings aggressively (`-Wall -Wextra`) to catch issues early.

## Typical exam/interview angles

- Explain difference between `int main()` and `auto main() -> int`.
- Explain implicit narrowing vs deduced common type in mixed arithmetic.
- Read a small code sample and predict output after type conversions.
